# Hi, I'm the founder of NumbersStore 👋

**Building privacy-first SMS verification infrastructure.**

Real non-VoIP numbers for SMS verification in 150+ countries. We help developers, businesses, and privacy-conscious users verify accounts without exposing their personal phone numbers.

---

## 🚀 What is NumbersStore?

NumbersStore provides **real, carrier-grade, non-VoIP phone numbers** for SMS verification and OTP reception. Our platform is built for:

- **Developers** — REST API + Webhooks for automated verification
- **Privacy-conscious users** — protect your real phone number
- **Businesses** — scalable verification infrastructure
